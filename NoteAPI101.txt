- Flow Login
1. POST /users (สมัครสมาชิก)
   → รับ password → hash ด้วย bcrypt → เก็บลง DB

2. POST /auth/login (เข้าสู่ระบบ)
   → รับ email + password
   → ดึง user จาก DB
   → bcrypt.compare(password, hashedPassword)
   → ถ้าตรง → สร้าง JWT token → ส่งกลับ

3. GET /users (ต้อง login)
   → ส่ง Header: Authorization: Bearer <token>
   → JwtAuthGuard verify token
   → ถ้า valid → อนุญาตให้เข้าถึง
